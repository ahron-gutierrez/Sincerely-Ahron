`FinalFontAhron-Regular.otf` is saved here for future use but is not currently enabled. To use it, update the `@font-face` source in `src/styles/App.css` to:

```css
src: url("/fonts/FinalFontAhron-Regular.otf") format("opentype");
```

The `.handwritten` class already uses the `AhronHandwriting` family with a system handwriting fallback.
